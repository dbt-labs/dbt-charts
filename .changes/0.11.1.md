## 0.11.1 (2026-11-04)
### Breaking changes
- Agents start from one `chart` skill: `dct skills intro`, `board-build`, `board-design`, the review and troubleshooting skills and the layout-pattern skills are removed, and naming one is an error.
- `dct docs` and the agents' `docs` tool are removed; agents read `dct skills chart`, people read the docs site.
- dct init no longer prompts: it always installs the dct agent skill, skips MCP setup, and prints the VS Code extension link; its --yes, --skills, --mcp, --vscode and --cursor options are removed.
- A trend annotation that reads an area mark is now a compile error; draw that column as a line or scatter layer instead. A trend over bars now warns.
- `type: http` queries and `http` sources are removed; load that data into your warehouse, or use a committed CSV, JSON or Parquet file source instead.
- Put a chart anywhere in a markdown board with a `charts` fence, which replaces the `{{ chart name }}` line; move each such line into a fence.
- Variables in a dbt-Jinja query with no source are now bound as values instead of pasted into the SQL text: write ILIKE '%' || {{ v }} || '%' instead of ILIKE '%{{ v }}%'.
### Features
- Secondary text is now the named font style.fonts.secondary, replacing style.muted (existing boards migrate automatically), and table row numbers, table and spark_bar notes, and the spark_bar subtitle each have their own font slot.
- Markdown tables in board text size their columns to their content.
- Readers can sort and filter a table in the page on interactive surfaces.
- Add `dct exposures` to write a dbt exposure per board, so boards appear in dbt lineage. [Closes dbt-labs/dbt-charts#72](https://github.com/dbt-labs/dbt-charts/issues/72)
- `dct cloud connection create` binds the project's sources in the same call with `--project` and `--map-source` or `--map-all-sources`.
- Board `text:` can list project boards and folders with `glob_boards` and `glob_folders` to build navigation. [Closes dbt-labs/dbt-charts#38](https://github.com/dbt-labs/dbt-charts/issues/38)
- `dbt-grays` and `dbt-creams` steps are now addressed by number (`dbt-grays.8`), with `0` white and `100` black; old step names migrate automatically.
- A table prints integer columns whole and year columns without a thousands separator.
- Derived axis, legend and table labels are sentence case and read units as units, so `weight_in_lbs` becomes 'Weight (lb)', and titles and headers without an explicit `case` print as written.
- `dct init` no longer writes a starter board; `dct serve` shows an intro page until the project has one.
- `dct` prints errors before warnings and lists keys that restate a default in one compact block; `WARN-UNREFERENCED-QUERY` flags a query no chart reads.
- Keys that restate a default, an inferred value or a column's default format now warn with `WARN-RESTATED-STYLE`, `WARN-RESTATED-INFERRED` or `WARN-RESTATED-FORMAT`.
- Custom chart templates can call a `d3` namespace of linear, sqrt, log, power, symlog, band, point and UTC time scales, ticks, curves, arcs, symbols, pie, stack and sankey layouts, map projections, geo paths, number and date formats and color mixing instead of hand-rolling the math.
- A custom chart template can print a value with its column's format using `format(column=...)`.
- A `daterange` value can be a rolling preset such as `last_90_days`, resolved on every render. [Closes dbt-labs/dbt-charts#73](https://github.com/dbt-labs/dbt-charts/issues/73)
- Boards with tabs run only the open tab's queries; set `cache: prefetch: true` to load the other tabs in the background.
- Section titles get their own size ladder, `style.fonts.section.sizes` (21, 18, 14, 11, 11 from H2), so a section title sits one step above the chart titles under it; boards with titled sections re-size on upgrade, and `style.fonts.section.size` is rejected.
- `regional.time_zone` sets the zone a board resolves its daterange presets in and prints its data-freshness stamp in.
- Annotate cartesian charts with rules, bands, notes and trend lines. [Closes dbt-labs/dbt-charts#23](https://github.com/dbt-labs/dbt-charts/issues/23)
- Markdown headings follow the board's heading sizes, sit on the body line grid, use the theme's heading case, and line up with chart titles in the same row.
- Hosts can register buttons into a toolbar the hover runtime draws at every chart's top-right (`registerChartButton`), with info, filter, and share slots.
- Serve every board in a project as one Streamlit app with `st_project()`, navigated like `dct serve`.
- Add `dct import looker`, which fetches a Looker dashboard into a source bundle for migration.
- Add `dct import hex`, which fetches a published Hex app into a source bundle for migration.
- dct import omni writes a source bundle from an Omni dashboard, and --list enumerates dashboards.
- dct import sigma fetches a Sigma workbook into a source bundle, and lists workbooks with --list.
- A bar, area, or pie chart that sets a board variable with a ?name={{ color }} link keeps the selected value at full strength and recedes the other marks, with their labels and legend entries, in SVG, PNG, and PDF.
- search_files results now list the sources a project's SQL can name, so AI agents don't need to read dbt_charts.yml to find them.
- A layer can decline its legend entry with `legend: false`, and a constant reference line draws no automatic point marks.
- Snowflake sources accept workload_identity_provider and workload_identity_entra_resource for workload identity authentication.
- Values queries reject a column that mixes kinds or holds only nulls when the board is validated.
- Athena array, map and row columns must be cast to JSON in the query; uncast they raise an error naming the column.
- Temporal x-axis labels center on the period they name; first and last data points get labels on on-tick axes.
- Add a chart-level `tooltip:` list that puts extra query columns on the hover card of bar, line, area, scatter and pie charts.
- Add `good: up` or `good: down` to KPI headlines and support lines so the glyph and color follow the value's sign.
- Value-label crowding warnings now cover time axes, layer labels, and labels wider than the bar they sit inside.
- dct init skills writes one versionless `dct` skill that sends agents to `dct skills chart` once a session, replacing the seven per-skill copies that went stale on every upgrade.
- Agent skill pages teach annotations, target lines, pacers and named chart shapes such as bullet and waterfall.
- A gradient scale's `nice` option now rounds the color domain on table columns, color channels, and maps, not only heatmaps, and rounds by default wherever the gradient draws a legend.
- Add `locked_schema_version` to dbt_charts.yml to pin the board syntax a project targets: `dct validate` and Cloud reject newer syntax, `dct migrate` stops at the lock, and warnings added after that release are silenced.
- Timestamps printed in titles and text show the board's regional.time_zone; a timestamp without a zone prints as written.
- Tables, KPIs, sub-day axis labels and tooltips print time-zone-aware timestamps in the board's regional.time_zone.
- Time axes on a board with a non-UTC `regional.time_zone` bucket timestamps on the zone's calendar days and place their ticks on its local midnights, across daylight-saving changes.
- Custom chart templates can call label_ink(color) and variant(color, kind), the engine's color math.
- Table spark bars no longer draw value labels; `value_visible` and `value_suffix` are dropped from existing boards with a notice to add a value column.
- Line and bar value labels accept `visible: last` to label only each series' most recent value.
- The `board-migrate` skill (formerly `board-replicate`) migrates Looker, Sigma, Hex, Omni and screenshot dashboards with SQL modes and per-source rules.
- Boards can query a source's MetricFlow semantic bundle with `AGG()` and relationship paths; `dct semantics` lists what a bundle declares, `dct query --validate` compiles semantic SQL and suggests the declared names a mistyped one nearly matches, `dct skills semantic-query` teaches the grammar, and a source can mark its bundle required so every query on it goes through the bundle.
- Line charts accept `connect: <column>` to connect points in that column's order instead of x order, for connected scatters.
- The dbt Charts skills now guide saving boards over the dbtcharts.com Claude and ChatGPT connector.
- Daterange presets follow a grammar (last_30_days, previous_3_quarters, this_fiscal_quarter) and the picker's preset menu is configurable.
- Board tabs size to their labels, the active tab stands out with a rounded outline, and a tab's title no longer repeats as a heading inside its pane.
- Hovering a legend entry or series name previews that series, and clicking one shows only it and zooms the value axis to it, with each further click adding or removing a series while the plot stays the same size.
- Set a board's fiscal year with regional.fiscal_year_start_month; fiscal daterange presets follow it instead of the chart axis setting.
- Add the daterange preset `before_previous_<N>_<unit>`: everything before the previous N units, with no lower bound.
- Bar, area, pie, and heatmap charts take a pattern channel and style.pattern, filling marks with hatch, dot, and dash textures.
- Histograms pick round bin widths that give about ten bins, so a column from 0 to 12 draws 13 bins of 1 instead of 6 of 2.
- Table column menus name each sort by the column's type (A → Z, 1 → 9, oldest → newest), add Select all and Clear to the value list, and filter date columns by a range picked on the calendar the date controls use.
- Line, area and scatter value labels now step off marks and other labels they would cover, and a label with no clear spot is not drawn; setting position, dx or dy keeps a label in place. Scatter value labels are now gray by default.
- Hover tooltips on stacked and grouped charts list up to 100 series (was 20); `style.charts.tooltip.max_rows` and `group_limit` set the cutoffs. [Closes dbt-labs/dbt-charts#77](https://github.com/dbt-labs/dbt-charts/issues/77)
- Boards with two or more filters show a Reset control that returns every filter to its default. [Closes dbt-labs/dbt-charts#79](https://github.com/dbt-labs/dbt-charts/issues/79)
- Narrative notation, the KPI headline default, writes million as `m` (`$59.1m`) instead of `mn`.
- dct cloud connections and the Cloud connections API name the identity each connection authenticates as, the principal to grant when a board hits a warehouse access error.
- Change every member holding one role to another with `dct cloud member role-all ROLE --from ROLE`, with `--dry-run` to preview.
- A line or area chart that joins straight across periods missing from its data now warns and names the NULL-row fix.
- Long select and multiselect filter menus have a search box.
- dbt Charts installs and runs on Python 3.14.
- The board migrate skill writes clean SQL from each chart's intent, keeps dbt Charts' visual defaults, and maps date controls to calendar-aligned presets.
- Set boards_dir in dbt_charts.yml to serve boards from a folder other than charts/.
- The MCP server's find_queries tool finds the boards and queries that answer a question with their cached rows, and execute_sql with a board reads them with no warehouse call.
- Table warnings name the column: a header over two lines and text wrapped into a tall narrow block each warn, replacing the table-cramped warning.
- Boards warn when text opens with a heading and no `title:`, as `WARN-BODY-HEADING-NO-TITLE`, replacing `WARN-H1-BODY-NO-TITLE`.
- A `dct search` hit names the query behind each matched chart, so `dct query` can follow it directly.
- Migrated boards keep the source's chart stacking and axis bounds, turn headings and notes into titles and text instead of callouts, carry Sigma table totals as KPIs, draw total rows only where the source shows them, keep Looker's ∅ for empty values, and translate Looker offset windows exactly.
- Draw `charts` fences on any site with `dbt_charts.integrations.markdown` in MkDocs or Pelican, replacing the `!!python/name` fence setup, or `dct render --format md` for Hugo, Jekyll, Astro and GitHub READMEs.
- A dual-axis chart can style each axis's grid lines, tick labels, and title with an axis color, and grid dash now renders.
- Long filter menus can show only the selected values and sort their values A to Z or Z to A.
- `dct describe` text output prints each query's SQL and accepts a board's title in place of its path, and `dct search` takes several unquoted words as one query.
- Line, point and bar value labels accept a list of anchors, any of `first`, `last`, `min` and `max`, to label only those values of each series.
- Column-bound filter menus show each value's row count and can sort by it.
- Hovering a series name brings its line and dots to the front, filtered stacked charts keep every series label, and a × CLEAR control resets a chart's series filter in one click.
