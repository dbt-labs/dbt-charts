## 0.12.0 (2026-11-20)
### Breaking changes
- A KPI's conditional formatting moves to `style.conditional` and its background to `style.background`; a `default` rule now applies only when no other rule in its column matched, and a rule that sets a glyph or a headline `tone` no longer migrates, so remove it (`good` picks the glyph).
- A `pow`, `sqrt` or `symlog` axis scale on a line, area, bar or histogram chart is now a compile error instead of silently drawing linear; use a scatter or remove the scale type. The log-scale error and the axis-scale docs no longer recommend symlog on bar or line charts.
### Features
- `style.key` replaces `legend` and `endpoint_labels`: `key.type` picks a legend or direct labels, `key.visible` hides the key. Boards migrate; custom templates reading `charts.series_label.font` or `endpoint_labels.label_offset` must move to `key.direct`.
- Bar, line, area, scatter, pie, heatmap, map and point-map charts restyle a mark by its row value with `style.conditional`, and a run of matching points restyles a line stroke or area fill.
- A table's conditional formatting moves to `style.columns.<column>.conditional`, where each rule sets the column's cell style (`background`, `font`, `glyph`), and `style.row.conditional` restyles a whole row, or another cell in it, from any column's value. Existing boards migrate automatically.
- A chart's constant color moves from `style.color.static` to its primary mark, such as `style.marks.bar.color`; existing boards migrate automatically.
- Tables scroll their rows inside the tile under a pinned header by default, with a pager below that follows the scroll; set `style.pagination.mode: pages` for the pager alone. A scrolling table beside a wider or taller neighbor shows its full page of rows, and warns when its slot can't fit them.
- A table wider than its slot first wraps long headers onto two lines, then scrolls sideways inside the slot instead of squeezing its columns or painting cell text over the next column; `column_layout.freeze` pins its leading columns while it scrolls, and `column_layout.overflow: fit` restores the old behavior. [Closes dbt-labs/dbt-charts#83](https://github.com/dbt-labs/dbt-charts/issues/83) [Closes dbt-labs/dbt-charts#84](https://github.com/dbt-labs/dbt-charts/issues/84) [Closes dbt-labs/dbt-charts#78](https://github.com/dbt-labs/dbt-charts/issues/78)
- A table cut by the row or size limit says so in its pager.
- Tables hide query columns whose names start with an underscore; set style.hide_underscore_columns: false to show them.
- Table columns marked `list: true` draw list values one per line, and live boards open each row in place from its chevron.
- Table spark bars can show the cell's value beside the bar with `spark.value`, and a `bar` spark draws a background track when `spark.background` is set.
- Hover a table cell cut with an ellipsis to read its full value, and click the card to keep it open for copying. [Closes dbt-labs/dbt-charts#93](https://github.com/dbt-labs/dbt-charts/issues/93)
- Readers can sort and filter pivot tables from the column header menu. [Closes dbt-labs/dbt-charts#101](https://github.com/dbt-labs/dbt-charts/issues/101)
- HTML exports now sort, filter and page their tables in the browser, like a live board.
- Draw funnel charts with type: funnel, with labeled stages and ribbons joining ordered bars.
- A chart can leave out `x`, `y` and its other channels: the query's columns bind by position, dimensions first and the measure last.
- Charts with a multi-measure `y: [...]` accept `layers:`, and a chart with `layers:` accepts `tooltip:`; the rows go on the base marks.
- Value labels on a line, area or scatter layer can show only the first, last, lowest or highest points, in the layer's own color.
- Bar charts tear outlier bars on their own with `style.outliers`: a vertical bar at least 12 times the median bar (`median_multiplier`; `none` turns it off), or past an `axis_y.scale.continuous.domain` maximum, runs off the card's top edge with its value labeled and shows its true length on hover; `variant: torn_with_cap` instead cuts it at a break and floats its labeled cap above the plot.
- Set style.axis_y.grid.torn_baseline to tear a line chart's bottom edge like paper when the y-axis excludes zero.
- Value-axis labels can sit just above their gridlines with `axis_y.labels.position: above_gridline`, and the paper theme now sets it.
- Line charts break across a large gap in the data instead of drawing a straight line through it; set style.marks.line.connect to true to join every gap.
- Set a size channel's mark-area range and scale type with style.size on scatter and bubble map charts. [Closes dbt-labs/dbt-charts#98](https://github.com/dbt-labs/dbt-charts/issues/98)
- A band's label takes `style.marks.text.max_width` (pixels or `auto`) to set its wrap width in place of the band's own width.
- Chart links can read any column of the clicked row, not only the plotted channels.
- A chart with no results now shows a quiet No results card, and a KPI with no value shows a dash.
- Charts take date, time, and number column types from the warehouse's declared result schema instead of guessing them from the values.
- A board's column references match query result columns ignoring letter case, so `y: revenue` reads a `Revenue` column; two columns differing only in case raise instead of guessing. Warehouse sources now keep a quoted alias's spelling (`Q3-25`) instead of lowercasing it.
- Warehouse queries run in the board's regional.time_zone, so SQL date truncation matches printed times.
- filter_date_range takes is_naive_utc=true for a naive column that stores UTC; timestamp= now raises an error.
- A query that reads `{{ queries.X.cache }}` can now set `dialect:` and be written in your warehouse's SQL, which is translated to DuckDB.
- `dct query` runs a board query that reads another query through `{{ queries.X.cache }}`, executing the upstream once in memory, and `--cache PATH` shares that query-result cache file across runs.
- A dropdown fed by an options query uses `options.column` as its value column and shows counts only when the query sets `options.count_column`; the unused `options.label_column` key is removed, and a dropdown bound with `column:` lists its values without counts.
- Multiselect filters show the selected values as removable pills.
- input: radio now draws every option as a row of buttons, and style.variables.presets_display: buttons does the same for a daterange's presets.
- Hovering or dragging a slider shows the value it would pick.
- A filter's sort button now changes the order with each click and shows the order in force, instead of opening a menu. [Closes dbt-labs/dbt-charts#99](https://github.com/dbt-labs/dbt-charts/issues/99)
- Themes can set the comment highlight tints with style.comments.highlight and style.comments.highlight_new.
- Markdown boards default to a wider page: a 90-character line instead of 75. Set `style.text.column.max_chars` to change it.
- The Markdown extension takes a `variables` option for a page's variables, and no longer prints the frontmatter of a page with charts.
- Charts drawn from Markdown fences now show tooltips and hover emphasis: the extension adds the hover script to each page, and `dct runtime-js` writes it for other static sites.
- render_board checks a markdown page: its charts fences render together as the one board a host draws.
- `dct validate` warns again when a `rows:` list stacks long `text:` blocks, because each block can take its own column grid.
- A chart warns when its title or subtitle names a unit that contradicts its compacted (K, M, B, T) value axis.
- Line and area charts warn when an overlay legend sits on top of a line or point.
- dct doctor warns when profiles.yml is newer than the dbt manifest, which leaves ref() and source() pointing at the old schema.
- dct serve shows the board's nav and a loading state at once while a slow board runs its queries, and its URL accepts requests as soon as it is printed.
- dct serve shows a collapsible sidebar of the boards in a folder and keeps your filters when you switch between them. [Closes dbt-labs/dbt-charts#97](https://github.com/dbt-labs/dbt-charts/issues/97)
- `dct cloud comments` lists, adds, replies to, edits, resolves, and reopens board comment threads from the terminal, `--review` scopes a listing or a new thread to a review, and `--mention` notifies people and teams.
- `dct cloud project settings` and `dct cloud project set` read and change a project's settings, including whether the agent honors the repo's AGENTS.md and `require_linked_author`, which makes a pull request open only for a member with a linked GitHub account.
- dct cloud project connect github now names your repository itself and, with gh signed in, connects it without a browser step.
- `dct cloud projects --json` reports each project's repository URL.
- `dct cloud export-eval` writes a Platform project's approved question-to-SQL pairs as JSON Lines.
- Agents now read a short board-layout skill before laying out a board.
- The skill dct init installs names the BI tools board-migrate imports from, board-migrate walks you through putting API keys in a .env file, and a missing key error says where to create the key and how to load it.
- The board-migrate skill finds a tile's query in the warehouse's query history, screenshots a dashboard page the import could not render, wires a big board one tab per sub-agent, and tells an agent how to build a source bundle for a BI tool without an importer.
### Fixes
- A board's style.title.font.size, which never sized a title, is removed and migrated away; a chart's own title size is unchanged.
- A board that sets style.font.family now paints its digits in that family too.
- A dbt package's boards now run from its integration_tests project with --dbt-project-dir, using that project's profile.
- KPI label wrapping, table digit overflow, spark bar corner radius, and the gutter of a mirrored axis with hidden labels now draw correctly.
- dct query --validate now lints SQL on a dbt profile source in that warehouse's dialect, so BigQuery project IDs with hyphens no longer raise false parse errors.
- A click-to-filter link on a dated line or scatter x now carries the row's ISO date instead of 0NaN-NaN-NaN.
- A scatter's data-fit y axis moves a non-zero end that a dot sat on out one tick step, as the x axis does.
- Line and area charts now pad a continuous x axis like a scatter, so end points and bands no longer sit flush against the plot edge.
- Axis end labels now center on their ticks instead of being pushed inside the chart, so time axes keep finer label cadences without crowding.
- X-axis ticks no longer push a chart's baseline up, so charts with and without ticks line up across a row; ticks default to 4px.
- Percent axes whose values stay within 0 to 100% no longer extend past 100% or below 0%.
- Percent formats no longer reject large negative ratios, such as a -2,094% margin, as 0-100-shaped.
- Every value axis uses one compaction tier: a 1,500k axis now reads 1.5M, and scatter and histogram axes no longer mix tiers on one axis.
- A float (DOUBLE) column of years on a chart's x axis now reads as numbers, not as a time axis.
- Scatter, horizontal bar and line small-multiples charts now honor `labels.visible: false` on an axis, hiding its tick labels and releasing the space they took.
- A small-multiples chart with a layer now draws each panel's own rows in its base line instead of every panel's.
- An unreadable dbt profile now reports ERR-DBT-PROFILE-UNRESOLVED instead of ERR-INTERNAL.
- `dct cloud` output calls the two branches the repository branch and the dbt Charts branch instead of trunk and work branch.
- dct cloud render says how many renders it queued, and that they run in the background, instead of counting a batch.
- dct cloud status and the connect and status hints now match what Cloud does: boards render on their own after a sync or mapping, and the next-step lines name the token env var and --map-all-sources.
- A query that reads another query's result keeps its list and struct columns as real values instead of JSON text.
- Agent write_file refuses to overwrite a file that changed since the agent read it.
- The AI agent no longer repeats its opening plan before every round of tool calls.
- Trino sources accept restrict_to_host, which fails a query when the server sends a URL on another host or spooled results.
- Board SQL translated into BigQuery works again with sqlglot 30.29 and later.
- A JOIN without ON warns about the missing join predicate again with sqlglot 30.32 and later, and a BigQuery comma join now warns too.
- Legend swatches match their line's dash pattern and color, and a legend that runs out of room ends in a "+N more" note.
- A legend too wide for one row now wraps into as many columns as its labels fit, instead of two, without cutting names.
- Very dense bar charts draw visible bars, `key.legend.values` orders stacked-bar legends, and stacked-column series labels skip a thin final period.
- Horizontal bars center category labels, print dates by grain, no longer grow taller when you raise axis_x.labels.padding, and refuse axis_x.position and axis_x.ticks.visible: true.
- A horizontal bar with a reversed value axis (`x_reverse: true` or a descending `axis_y` domain) now grows leftward from a zero line on the right, with its category labels beside that line, and an authored `labels.visible: false` on a bar hides the `0` label too.
- Bar value labels: a label inside a bar reads against that bar and one too big for a short bar moves outside it, a stacked segment too short for its label hides it, labels on centered stacks sit at the end of each bar, and a label too small for its number format prints as a bound, such as <0.1, instead of 0.0.
- Bars with a color channel keep their width beside a step-curve line layer.
- Hover now recedes bars drawn with opacity, such as conditional opacity.
- Hovering a bar keeps a target line's dot without a drop line, and a step target's other segments fade with their bars.
- Hovering inside an area chart's fill now shows the data point at the cursor's position instead of jumping between nearby points.
- An area chart's white top edge no longer notches its zero baseline where the series runs at zero.
- A monthly bar chart with a support table labels every month again instead of falling back to quarters.
- Annotations on a chart edge keep their full width, x anchors and max() reach layer rows and numeric-x marks, a percent axis from 0 draws its 0% line, and floating legends no longer have gridlines cutting their text.
- Annotation rules draw one gray step darker than the axis baseline, so a rule no longer reads as an axis line.
- Bands: a band label centers on its band, wraps to its width, and stays centered when it moves to avoid a collision; on a time or ordinal date axis a band covers its whole buckets, half a step out on each side of its marks, so a band dated after the last week, month or quarter mark draws instead of vanishing; a band past the last point is clipped instead of widening the axis; and inside a shaded band the gap around each bar shows the band's color instead of white.
- Layer labels render Jinja, multiselects print as natural lists, and bad palette stops, roles, or off-plot line layers give clear errors.
- Series colors follow one rule on every chart type: pinned colors first, then the values' own order, then largest first, ranked on the board's unfiltered view so filters never reshuffle colors.
- A bare category[N] color token now indexes the board's own categorical palette when the board sets one, instead of always using the theme's.
- A chart that names the `RdYlGn` or `parula` palette now draws that palette, with a warning that recommends `dbt-div-crimson-green` or `dbt-seq-blue`, instead of silently drawing the recommended palette.
- A board-wide palette set for one chart type, such as `style.charts.line.color`, now colors those charts.
- A global `style.charts.marks.rect.stroke` no longer fails with `cap` and `join` errors.
- A pie whose color names a column the query lacks now reports which column is missing instead of crashing.
- A pie's attached table now lines up with the wheel on every edge; beside the wheel it keeps the wheel centered in the card, so the left and right sides look the same.
- A chart subtitle with no title now draws above the chart instead of disappearing.
- A chart placed more than once on a board keeps each placement's clip paths and masks apart.
- The text render of a percent chart now prints its y range at the precision the chart's axis shows.
- Compacted table columns repeat the magnitude suffix (K, M, B) on every row and no longer give every row extra decimals because one row is small; a value too small for the column's decimals prints as <0.01 M.
- Support-table rows name their unit in the row label and print bare numbers on one decimal grid, as a table column does, with `<0.01` for values too small for it and no stray float decimals; date strips keep a cell for every labeled period instead of skipping some.
- Tables with a total row first, sibling numeric columns, numeric-year support tables, and bottom support tables now draw their rules, number formats, years and spacing correctly.
- Pivot table cells and date column headers now use the same formats as a flat table, and a cell color scale spans the whole measure.
- In a table row where one cell wraps, every cell's first line now sits on the same baseline, and swatches and spark bars sit beside that first line.
- Paged tables on a live board are sized to the page they show: a few wrapping rows no longer shrink the page size, and a taller page scrolls inside the table instead of leaving blank space under every page.
- Table spark bar columns are wide enough to compare rows, a nonzero value always draws a visible bar, and a value of 0 draws an empty cell instead of printing 0. [Closes dbt-labs/dbt-charts#95](https://github.com/dbt-labs/dbt-charts/issues/95)
- A table spark on a text column now says the column must be an array of numbers instead of reporting an engine gap.
- Table header menus: a focused sortable header outlines its whole cell, clicking anywhere in the cell opens its menu, and sorting or filtering from a centered header no longer shifts its label.
- A table column's filter menu shows each value's conditional glyph in its own color.
- A KPI conditional rule that compares to an aggregate function now reports ERR-KPI-CONDITIONAL-AGGREGATE instead of an internal error.
- Bold text (such as a table cell with a conditional bold font) now stays bold in PNG and PDF exports.
- Boards no longer draw a rule above the footer (set style.footer.divider.visible: true to bring it back); on a board narrower than its footer the timestamp sits above the credit instead of on top of it, and a board sized to its minimum width no longer wraps the footer onto two lines.
- Variable controls that wrap onto more than one row split evenly instead of leaving one control alone on the last row.
- A read-only board shows a checkbox's and a slider's value as text, like every other control, instead of a form widget.
- Select and multiselect menus with many thousands of values open instantly and show the first 200, with search reaching the rest.
- A dropdown whose options come from a boolean, number or date column now accepts that value from a link or --var.
- A board that overrides one key of an inherited variable now keeps the rest of the variable, so its default and options still apply.
- A variable key that sets a value back to its default over a meta.yml or extends value is no longer reported as restated.
- A bordered board in a tab pane hugs its last row when card_gap is on.
- Clicking a board tab now shows the switch immediately: the tab is selected at once and its pane shows as loading until the new one arrives.
- Text in a card slightly wider than one column now wraps at the same width as the board's other single columns.
- A text block that is only a `---` rule now spans the whole card, and `style.text.column.max_chars` caps it. [Closes dbt-labs/dbt-charts#91](https://github.com/dbt-labs/dbt-charts/issues/91)
- A typo in a board's text or title, such as `{{ regoin }}`, now warns instead of rendering nothing.
- A chart whose own `visible:` reads a query renders instead of failing with "was not collected before render".
- A markdown page draws a charts fence whose text reads a query, when the host draws each fence on its own.
- A side-by-side example in rendered Markdown grows to fit a board taller than its YAML instead of spilling onto the text below.
- dct validate reports the correct line numbers for warnings in markdown boards, lists diagnostics in a stable canonical order, and no longer reports a read-only `{% if %}…{% else %}` filter as mutating SQL.
- Editing a DuckDB or SQLite file now refreshes cached results when a board source shadows a project source of the same name.
- A DuckDB source listing a built-in extension, such as json, no longer needs network access.
- Local CSV and Parquet file sources load on DuckDB 2.
- Automatic links and /data/ pages work on Snowflake.
- BigQuery stops downloading a result at execution.max_result_bytes, `dct query` and MCP query results on every warehouse are cut and flagged at the row ceiling and that budget, and bulk metadata queries that exceed it fail with an error.
- dct render now re-runs queries that failed on a missing table or column instead of replaying the cached error, and says when it replays any other cached query failure.
- A missing-table error suggests running dbt parse when the query uses ref() or source(), and a SQLite query on a missing table now reports ERR-BINDER-UNKNOWN-RELATION with that hint too.
- A schema, table or column that a schema query cannot find now reports a coded error.
- Warehouse permission-denied and credential failures now tell you to fix access or credentials instead of the SQL, connection and unknown-table errors name the source and the next command to run, and other warehouse errors include their next step.
- Error messages give advice that works for literal colors (and the fix keeps your color), unusable palettes, number formats the renderer can't draw, spreadsheet number formats, inline layer queries, Jinja in annotations, and mistyped query references.
- Validation errors name the path as written in your YAML, without the chart-type tag.
- Validation errors and warnings now name what the board accepts at that spot (a layout item's accepted forms, the drawn values behind an unseen category color pin, the defined Jinja variables), and `dct query` prints query warnings on success.
- Skill pages and ERR-EXTRA-FIELD list nested keys with their values, an explicit CROSS JOIN no longer warns, and three internal-sounding errors name the field and the fix.
- A category_colors pin no longer warns when a board variable's filter may be what hides the pinned value.

- Chart, query and variable names must be identifiers: letters, digits and underscores, not starting with a digit.
- An unknown query in a chart's query: now suggests the nearest declared query name.

- A numeric daterange default, or a list default on a select or radio input, now reports a validation error with its field path.

- dct describe finds a board by its title or file name despite stray whitespace, and suggests the nearest board paths when nothing matches.
- A board alias claimed by two boards fails just those boards in dct serve and dct validate instead of taking down every page.

- A board theme or `DCT_DEFAULT_THEME` that names the private `_base` fragment, or a `DCT_DEFAULT_THEME` that names an unknown theme, is now refused with a clear error everywhere, and `_base` no longer appears among the built-in themes.
- A replayed board artifact now draws its KPI and callouts as a live render does; artifacts written by earlier releases no longer load, so run `dct artifact emit` again.
- The docs and `dct skills chart` now say which YAML features board files accept and refuse, and which unquoted values YAML 1.1 reads as booleans or numbers. [Closes dbt-labs/dbt-charts#90](https://github.com/dbt-labs/dbt-charts/issues/90)

### Performance
- Boards render about twice as fast again in `dct render`, `dct serve` and the MCP tools, which no longer report the data-dependent WARN-RESTATED-INFERRED and WARN-RESTATED-FORMAT warnings. [Closes dbt-labs/dbt-charts#88](https://github.com/dbt-labs/dbt-charts/issues/88)
- Compiling a board is nearly twice as fast.
- Boards with large tables or several KPI cards render faster, and hovering a board that holds a large table no longer lags.
