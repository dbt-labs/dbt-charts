## 0.13.0 (2026-11-25)
### Features
- On a horizontal bar, `axis_x.position: left | right` now places the category names; boards that declare the bar horizontal migrate, others error with the fix.
- Every text line limit is `max_lines` (a line count or `all`): titles, subtitles, KPI labels and table headers take it in place of `overflow`, and table text cells wrap to the lines the column's ordinary cells need, with `style.max_lines` to choose a percentile, `square`, a line count or `all`. Tab labels are always one line, and older boards migrate.
- A tab can be hidden from the tab bar with `visible:`, set to false, a variable condition or a query probe. [Closes dbt-labs/dbt-charts#100](https://github.com/dbt-labs/dbt-charts/issues/100)
- `tabs` maps each tab's label to a full nested board: its `title:` heads the pane and `width:` and `height:` size it. The first tab opens on load; `id`, `default` and `icon` are gone, and `position` moved to `style.layout.tabs.position`.
- Heatmap cells can print their values with `style.marks.rect.labels`, in ink that reads against each cell's fill.
- Set `axis_x.type` to `nominal` to draw date-like labels, such as Oct 2025, as plain categories.
- Grouped bar charts overlap by default only when one series is clearly the bigger one.
- Line charts can tell series apart by stroke style from a line palette, selected by `style.palettes.line_category`.
- Legends take a symbol size, an entry gap, a background and a label halo through `style.key.legend`.
- The `dct artifact` commands (`emit`, `render`, `schema`) are removed; render a board with `dct render` instead.
- Themes can limit how thick category bars and columns grow, in pixels or as a percent of the plot, with `style.charts.bar.max_thickness`.
- Line and area charts can name each series inside the plot beside its own line with `style.key.direct.position: overlay`, following gentle lines as they tilt and bend; `auto` (the default) does so wherever every name fits, and `style.key.direct.overlay_x` pins a series name to an x of your choosing.
- Themes can move long horizontal bar names above their bars in narrow charts with `style.charts.bar.labels_above`.
- Set one ink with a hex `style.roles.ink`, and tell series apart by pattern by binding a pattern palette to `style.palettes.fill_category`; the new `pattern-one-ink` palette fills each series in that ink, from solid to open in even steps.
- Heatmaps and maps can draw in flat tints of one ink.
- Scatter charts can draw as a range frame with open series symbols.
- `locked_schema_version` accepts `latest` (the default when unset) and `preview`.
- Line charts and floating bars tear their edge by default when the value axis leaves out zero, and scatter plots can turn the tear on.
- Value labels now move off gridlines as dark as text, as on the stark theme, and when one bar label moves inside its bar the rest of its layer follow.
- BigQuery sources accept a `reservation` to run their queries in.
- A y-axis `domain` can now pin one end and fit the other to the data, as in `domain: [null, 1]`. [Closes dbt-labs/dbt-charts#107](https://github.com/dbt-labs/dbt-charts/issues/107)
- `dct migrate` names each key it changes, `--diff` prints a diff of each file, and a key inside a YAML anchor is reported by file and line for a manual edit. [Closes dbt-labs/dbt-charts#113](https://github.com/dbt-labs/dbt-charts/issues/113)
- Grouped bars now order their series by `style.series_order` (renamed from `style.stack_order`, migrated automatically), largest first by default.
- Order a folder's boards and subfolders in the `dct serve` sidebar and folder listing with `server.nav_order` in `dbt_charts.yml`. [Closes dbt-labs/dbt-charts#131](https://github.com/dbt-labs/dbt-charts/issues/131)
- Table columns take a `type:` to print a column as `text`, `number`, `date` or `datetime`.
- Click a chart mark to pin its tooltip open, and format a `tooltip:` entry `url` or `email` to show its value as a link. [Closes dbt-labs/dbt-charts#152](https://github.com/dbt-labs/dbt-charts/issues/152)
### Fixes
- `dct import sigma` places tiles on their pages when Sigma returns an empty workbook layout.
- A format hint no longer suggests a date grain name like `date_month` that the board has not redefined.
- The `dct examples` table and KPI specimens no longer set styles the defaults already provide, so agents stop copying them.
- Crowded annotation rule labels stay beside their own rules and in order, stepping onto extra lines or switching to circled numbers with a key.
- Value labels read cleaner: `currency_compact` data values print three significant figures (`$412k`), so two amounts no longer share a label; value and endpoint labels under a compact axis format print lowercase `k`/`m` while the axis keeps its capitals; a run of labels drops the unit the value axis already shows and any `.0` that adds nothing.
- Dashed lines, gridlines, dividers, borders and annotation rules start and end on a dash.
- `dct validate` now catches a variable whose options query is not declared.
- Error and warning links in CLI output and rendered boards now open the docs page for that code's topic.
- Boards no longer accept `style.variables.visible` or `style.charts.table.spark.bar.font`, which had no effect; a board that sets either is migrated automatically.
- Hovering a chart fades every label with its mark and brings a pointed-at series to the front.
- KPI and table cards now take `style.charts.background`, accept CSS color names, and round like other cards.
- Markdown in boards renders a bold link from bold around or inside the link, and underscores inside a word stay literal.
- Backslash escapes in Markdown text now print the escaped character without the backslash.
- Probing a table's readability no longer fails when the credential is granted only some of its columns.
- A query that inlines another query reading `{{ queries.X.cache }}` now runs over the cached rows instead of failing on an unknown `__dct_cache_ref__` table.
- A line end or dot that reaches the axis no longer hides its tick label, and tick marks sit under the data.
- `dct serve --detach` and `dct-playground` no longer fail with "port in use" when another process takes the chosen port while they start.
- A chart that reads a truncated `{{ queries.X.cache }}` result now carries the truncation warning itself, on cached renders too.
- Value labels on pattern-filled bars sit on a clear ground and stay readable.
- Hovering a bar past its chart's axis curls it outside the plot or draws it straight, never over the plot, and leaves its value label in place.
- The selected tab in a tabs layout now takes its pane's background color.
- A line or area chart on a numeric x column now shows the column's format in the hover card header. [Closes dbt-labs/dbt-charts#104](https://github.com/dbt-labs/dbt-charts/issues/104)
- Torn outlier bars no longer hide their chart's title, subtitle, legend, or labels above the plot, and show more bar above the title. [Closes dbt-labs/dbt-charts#123](https://github.com/dbt-labs/dbt-charts/issues/123)
- `style.outliers.reveal: none` is retired; boards that set it migrate to `chart`.
- `dct serve` runs the background tab prefetch again with FastAPI 0.142 and later, instead of logging an AttributeError on every board. [Closes dbt-labs/dbt-charts#133](https://github.com/dbt-labs/dbt-charts/issues/133)
- `dct serve`'s sidebar, search and board listings name a board whose title is a template by its file name instead of showing the template. [Closes dbt-labs/dbt-charts#119](https://github.com/dbt-labs/dbt-charts/issues/119)
- A DuckDB source that attaches a Quack database now fails with a clear error, because Quack cannot attach read-only; local users can opt in to a writable attach with `read_only: false`. [Closes dbt-labs/dbt-charts#125](https://github.com/dbt-labs/dbt-charts/issues/125)
- WARN-FORMAT-UNUSED-NAME no longer fires for a `style.formats` name that text reaches through `format(<expression>)`. [Closes dbt-labs/dbt-charts#122](https://github.com/dbt-labs/dbt-charts/issues/122)
- WARN-REAGGREGATION no longer fires on `COUNT(DISTINCT IF(...))` or `COUNT(DISTINCT CASE ...)` when the aggregated column appears only in the condition. [Closes dbt-labs/dbt-charts#115](https://github.com/dbt-labs/dbt-charts/issues/115)
- A chart whose query returns no rows, or whose axis column holds only nulls, now renders when its axis format uses a notation such as `currency_compact`, instead of failing the board. [Closes dbt-labs/dbt-charts#144](https://github.com/dbt-labs/dbt-charts/issues/144)
- PNG and PDF exports of a table that scrolls on screen now size its card for the squeezed table, so rows no longer page out under the board footer.
- A query that filters on a board variable keeps its dbt column check, so a misspelled model column still fails validation. [Closes dbt-labs/dbt-charts#137](https://github.com/dbt-labs/dbt-charts/issues/137)
- Hiding an axis title with an empty `y_label` or `x_label` no longer blanks that row of the chart's hover card, on faceted charts, layers and support tables too. [Closes dbt-labs/dbt-charts#134](https://github.com/dbt-labs/dbt-charts/issues/134)
- Charts in titled boards side by side in a `cols:` row end level again when one board's title wraps. [Closes dbt-labs/dbt-charts#111](https://github.com/dbt-labs/dbt-charts/issues/111)
- `dct validate` now rejects a table `conditional` rule, or a `style.row.conditional` rule's `columns.<col>`, that sets `tone` or `glyph_color` with no glyph for that cell, instead of the board failing at render. [Closes dbt-labs/dbt-charts#112](https://github.com/dbt-labs/dbt-charts/issues/112)
- Variable value errors now say a select takes one value, show the JSON list a multiselect needs, and list at most 10 options. [Closes dbt-labs/dbt-charts#114](https://github.com/dbt-labs/dbt-charts/issues/114)
- Bar direct labels now show each series' display label, including `field_labels`, matching the legend. [Closes dbt-labs/dbt-charts#108](https://github.com/dbt-labs/dbt-charts/issues/108)
- Palette tokens in a `point_map` basemap's fill and stroke now resolve to their colors instead of painting black. [Closes dbt-labs/dbt-charts#139](https://github.com/dbt-labs/dbt-charts/issues/139)
- A `point_map` legend now follows the order and selection in `style.key.legend.values`. [Closes dbt-labs/dbt-charts#140](https://github.com/dbt-labs/dbt-charts/issues/140)
- A chart, variable or query reference whose file name starts with a digit, such as `1_source.charts.revenue` or `1_source.queries.sales`, now reports an invalid reference instead of ERR-WRONG-SHAPE or ERR-SOURCE-REQUIRED. [Closes dbt-labs/dbt-charts#126](https://github.com/dbt-labs/dbt-charts/issues/126)
- A table column's `font.decoration` and `font.style` now style its cells, not only when set by a conditional rule. [Closes dbt-labs/dbt-charts#130](https://github.com/dbt-labs/dbt-charts/issues/130)
- A heatmap's `sort:` no longer reorders a date axis, so each cell stays under the date its label shows; a sort over two date axes is now an error. [Closes dbt-labs/dbt-charts#142](https://github.com/dbt-labs/dbt-charts/issues/142)
- A map placed beside another chart in a `cols:` row now appears in PNG and PDF exports. [Closes dbt-labs/dbt-charts#138](https://github.com/dbt-labs/dbt-charts/issues/138)
- A percentage `width:` in a `cols:` row is now the same size whatever the row's column count, so cards line up across rows when a gap is set. [Closes dbt-labs/dbt-charts#110](https://github.com/dbt-labs/dbt-charts/issues/110)
- Line end labels on a log y axis now sit level with their lines instead of stacking away from them. [Closes dbt-labs/dbt-charts#136](https://github.com/dbt-labs/dbt-charts/issues/136)
- A KPI keeps its own height, as a table does, instead of stretching to a taller slot such as a `cols:` row or a `grid:` span; a chart's own `style.default_height` sizes its KPI card, and `style.label.max_lines: all` draws every label line. [Closes dbt-labs/dbt-charts#106](https://github.com/dbt-labs/dbt-charts/issues/106)
- Area layers draw each fill from zero to its own value instead of stacking, so adjacent bands no longer draw as slanted wedges, and an area layer over a horizontal bar that is split by color, stacked, or plots a list of measures now renders. [Closes dbt-labs/dbt-charts#116](https://github.com/dbt-labs/dbt-charts/issues/116)
- Under `overflow: fit`, as in every PNG and PDF export, a table's pinned column widths now give way before other columns break words mid-letter, and text that still cannot fit is cut with an ellipsis. [Closes dbt-labs/dbt-charts#143](https://github.com/dbt-labs/dbt-charts/issues/143)
- A date written in an inline values query is now treated as a date everywhere it is drawn.
- The layered-chart scale-mismatch warning no longer fires on a goal line that sits beside its data on a zoomed axis, and its advice now suggests same units or two charts.
- A histogram now rejects `style.axis_x.type`, set on the chart or cascaded from `style.charts.histogram` in a board or theme, which it used to ignore silently; remove the key, since a histogram's x scale is always continuous.
- A layered chart's `y_label` titles only its shared y axis, as written, and the base series' legend entry keeps its column's field label; `dct validate` now reports a layer `axis_y` title or style when no layer pins a side. [Closes dbt-labs/dbt-charts#141](https://github.com/dbt-labs/dbt-charts/issues/141)
- A gradient's range is now `domain: [min, max]` (or `{min, max}`, `null` for an open end), the same as an axis's, so `domain: [0, 100]` works; boards that set `min`/`max` migrate automatically. [Closes dbt-labs/dbt-charts#109](https://github.com/dbt-labs/dbt-charts/issues/109)
- Line and area charts with endpoint labels leave the same headroom above the data as every other chart, instead of rounding the value axis up to a clean tick.
- Sidebar links in `dct serve` no longer carry the current board's filters to other boards.
- A table's text column prints its cells as stored instead of reading dates or numbers out of them, and no longer fails to render when its cells look like numbers. [Closes dbt-labs/dbt-charts#135](https://github.com/dbt-labs/dbt-charts/issues/135)
- Text renders of a heatmap authored with `y: [a, b]` now name each measure and summarize its range instead of dropping them.
- The YAML reference and `dct skills chart` now show the `format` filter for query values in `text:` and titles, instead of saying to format them in SQL. [Closes dbt-labs/dbt-charts#148](https://github.com/dbt-labs/dbt-charts/issues/148)
- `filter()`'s deny-on-unset keyword is now `unset=` (`filter('status', status, unset='deny')`), so it passes `dct validate`; the documented `none=` never parsed. [Closes dbt-labs/dbt-charts#147](https://github.com/dbt-labs/dbt-charts/issues/147)
- A chart with annotations whose query returns no rows shows "No results" instead of failing with ERR-ANNOTATION-INVALID. [Closes dbt-labs/dbt-charts#155](https://github.com/dbt-labs/dbt-charts/issues/155)
- `input: range` is retired: it was a one-value slider, so boards that use it now migrate to `input: slider`; a two-ended range is two slider variables. [Closes dbt-labs/dbt-charts#145](https://github.com/dbt-labs/dbt-charts/issues/145)
- Rule annotation labels above the plot no longer overlap a top legend. [Closes dbt-labs/dbt-charts#156](https://github.com/dbt-labs/dbt-charts/issues/156)
- A horizontal bar chart now warns when its category count forces it taller than the `height` or `style.max_height` set on the chart.
- `style.marks.bar.size` sets the width of bars on a category axis.
- A `category_colors` pin inherited from `meta.yml` or `extends:` no longer warns `WARN-CATEGORY-COLOR-PIN-ORPHAN` on boards that do not color by its field. [Closes dbt-labs/dbt-charts#117](https://github.com/dbt-labs/dbt-charts/issues/117)
- Default outlier tearing no longer warns on a horizontal or stacked bar chart. [Closes dbt-labs/dbt-charts#118](https://github.com/dbt-labs/dbt-charts/issues/118)
- Time axes on bar, line and area charts keep every label that fits the plot, so a quarterly axis that starts in Q4 no longer drops to one label a year. [Closes dbt-labs/dbt-charts#128](https://github.com/dbt-labs/dbt-charts/issues/128)
