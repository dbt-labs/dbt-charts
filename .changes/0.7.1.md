## 0.7.1 (2026-09-11)

Scatter charts gain multi-y support, the VS Code extension now auto-updates, and `dct playground` moves to the hosted app.

- **`dct playground` now opens the hosted playground; `--with-playground` removed:** `dct playground` no longer boots a local server — it opens/prints the hosted https://play.dbtcharts.com/ URL instead. The `dct init --with-playground` flag and the `playground` pip extra are gone (#8888).
- **Scatter charts support multi-y (`y: [a, b]`):** Scatter is now the last cartesian chart type to accept `y: [a, b]`, folding multiple measures into a color series the same way bar, area, and line already do. Tooltips, click interactivity, mirror axis, and related warnings all work with it (#8865).
- **Editor extension installs now auto-update via the Marketplace/Open VSX:** `dct init code|cursor|vscode` installs the dbt Charts extension by its published Marketplace/Open VSX ID instead of side-loading a VSIX from an internal bucket, so it now auto-updates through the editor (#8890).
- **Fixed PDF export failing on deeply nested report boards:** `dct render --format pdf` no longer fails with an SVG-nesting-depth error on large multi-section report boards; PNG export was never affected. Caused by inert no-op group wrappers counting against PDF's 28-level nesting limit (#8859).
- **New warning flags unstacked area charts that read as stacked:** `dct render`/`dct validate` now warn when a multi-series `type: area` chart without stacking is visually indistinguishable from a stacked one, since every band fills to zero and the outer edge can be misread as a total (#8852, #8896).
