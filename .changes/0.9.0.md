## 0.9.0 (2026-10-01)
### Features
- The `render_board` agent tool (`dct mcp`, `dbt_charts.ai`) returns a compact text summary instead of JSON with every row, and no longer takes `format`. Set `include_raw_data: true` to also get the rows. `dct render` gains `--format text-data`.
- Amazon Athena support: install `dbt-charts[athena]` and point a source at an Athena target with `type: dbt_profile`. [Closes dbt-labs/dbt-charts#7](https://github.com/dbt-labs/dbt-charts/issues/7)
- ClickHouse support: install `dbt-charts[clickhouse]` and point a source at a ClickHouse target with `type: dbt_profile`. The read-only user needs `readonly = 2`. [Closes dbt-labs/dbt-charts#26](https://github.com/dbt-labs/dbt-charts/issues/26)
- `ProjectSession.render_board` accepts `compile_result=` to render an already compiled board without compiling it again.
- Streamlit support: `st_board(board, project_dir=...)` from the `dbt-charts[streamlit]` extra renders a board with live variable controls. Pass a Snowpark session to run `snowflake` queries through it.
- `dct render --format text` shows formatted values: KPI values, chart value ranges, table column labels and formats, plus render warnings.
- Date and datepicker controls have a "Today" button.
- Endpoint labels, stacked-bar rails, pie slice labels, and support-table strips derive their label color from each mark color against the chart background, so custom palettes and dark themes get legible labels. Tune it under `chart_rendering.color_variants` in `dbt_charts.yml`.
- Every categorical palette offers derived variants via a trailing token: `category.blue.dark`, `category[2].light`, `vivid-10.3.pale`, or a whole list such as `vivid-10.deep`. The companion palettes (`vivid-10-dark`, `editorial-10-ghost`, ...) and the `category_dark`, `category_light`, `category_ghost`, and `category_ink` roles are retired. Boards and themes are migrated on load and by `dct migrate`, except a nested board's own `charts:` block and a KPI background scale palette, which fail to compile with an error naming the new spelling. `dct migrate` does not rewrite retired tokens inside a flow-style list.
- Bars and bar layers accept `y_start`, for floating bars, dumbbells, waterfalls, candlesticks, and gantts.
- Board text warns when heading or body text has too little contrast against its row background.
- Stacked area charts accept `style.stack_order`; `data` stacks a `y:` list in authored order.
- `dct skills intro` covers board basics; `dct --help`, `dct skills`, and `dct init` point to it.
- dbt Charts now warns (`WARN-DUAL-AXIS-COMPETING-SCALES`) when a layered chart pins a layer to its own y-axis with `axis_y.position`, because the two independent scales make crossings and relative height artifacts of the axis ranges. To show one quantity in two units, drop the layer and relabel the opposite edge with `style.axis_y.mirror` and a converting `expr`. The layered-scale-mismatch warning no longer suggests adding a second axis.
### Fixes
- CJK, kana, and hangul text is measured at full width, so `text:` paragraphs wrap instead of clipping. [Closes dbt-labs/dbt-charts#6](https://github.com/dbt-labs/dbt-charts/issues/6)
- A single-series horizontal bar with an attached `support_table` keeps its value-descending sort. [Closes dbt-labs/dbt-charts#8](https://github.com/dbt-labs/dbt-charts/issues/8)
- `dct validate --warehouse` no longer crashes with `AssertionError` on a board that relies on an auto-detected dbt project with no `sources:`. [Closes dbt-labs/dbt-charts#11](https://github.com/dbt-labs/dbt-charts/issues/11)
- Jinja inside a query referenced via `{{ queries.X }}` is rendered instead of sent to the warehouse verbatim. [Closes dbt-labs/dbt-charts#12](https://github.com/dbt-labs/dbt-charts/issues/12)
- The color-reuse warning scales with palette size and fires on line, area, and stacked bar charts with endpoint labels. [Closes dbt-labs/dbt-charts#14](https://github.com/dbt-labs/dbt-charts/issues/14)
- Heatmap axes follow query row order by default, and `sort:` applies to y as well as x. [Closes dbt-labs/dbt-charts#13](https://github.com/dbt-labs/dbt-charts/issues/13)
- `multiples:` panels follow query row order instead of sorting alphabetically. [Closes dbt-labs/dbt-charts#18](https://github.com/dbt-labs/dbt-charts/issues/18)
- A date format on a numeric table column, or a number format on a date column, raises `ERR-TABLE-FORMAT-KIND-MISMATCH` instead of `ERR-INTERNAL`. [Closes dbt-labs/dbt-charts#16](https://github.com/dbt-labs/dbt-charts/issues/16)
- Date-valued KPIs honor date formats and default to `date_short`. Time directives (`time_short`, `%H:%M`) show the actual time instead of midnight. [Closes dbt-labs/dbt-charts#15](https://github.com/dbt-labs/dbt-charts/issues/15)
- `grid.columns` must be positive and spans and sizes must not be negative; `columns: 0` crashed `dct render`. [Closes dbt-labs/dbt-charts#17](https://github.com/dbt-labs/dbt-charts/issues/17)
- Grouped bars with a numeric or boolean color field render instead of raising `ERR-CHART-PAINTED-NO-MARKS`. [Closes dbt-labs/dbt-charts#19](https://github.com/dbt-labs/dbt-charts/issues/19)
- `WARN-BAR-BAND-WIDTH-TOO-NARROW` fires on horizontal bar charts.
- Warehouse connection failures show an actionable message instead of the driver's raw exception text, which moves to a separate `detail` field.
- Date and datepicker controls use their own calendar popover and label format, matching daterange, instead of the browser's native date input.
- Time axes with an authored `time_format` no longer overprint tick labels. When no layout fits, labels are dropped and `WARN-AXIS-LABEL-COLLISION` fires.
- The `cloud-setup` skill states its requirements up front: pushing to the default branch and a read-only warehouse credential.
- `dct init skills` reports an unwritable directory instead of a `PermissionError` traceback. `dct render --output` creates missing parent directories. `dct cloud status` warns when the working directory is not tied to a project. `dct cloud project connect --git-url` warns that github.com repositories need the GitHub App flow.
- A dual-axis layer with its own `axis_y.labels.format` no longer triggers `WARN-LIKELY-CURRENCY-OR-PERCENT-MISSING-FORMATTER`. [Closes dbt-labs/dbt-charts#30](https://github.com/dbt-labs/dbt-charts/issues/30)
- `dct render`, `dct validate`, and `dct describe` resolve a relative board path from the working directory first.
- "No dbt charts project found" errors say to create `dbt_charts.yml`; an empty file is enough.
- `ERR-FORMAT-NATIVE-IN-VEGA-SLOT` no longer suggests a `.1%` spec for `percent_number` formats, which painted values 100 times too large.
- A `support_table` `aggregate:` row no longer adds a phantom "undefined NaN" tooltip row. [Closes dbt-labs/dbt-charts#29](https://github.com/dbt-labs/dbt-charts/issues/29)
- A `support_table` row's `source:` works with column names containing spaces, hyphens, or other special characters. [Closes dbt-labs/dbt-charts#32](https://github.com/dbt-labs/dbt-charts/issues/32)
- When a stacked bar's color maps one-to-one to its x categories, the legend and stack order follow the x order (`sort:` or query order) instead of stacked totals. [Closes dbt-labs/dbt-charts#28](https://github.com/dbt-labs/dbt-charts/issues/28)
- Line and area `stroke.width` set at board, theme, or `meta.yml` level is honored instead of replaced by the density-based default. [Closes dbt-labs/dbt-charts#37](https://github.com/dbt-labs/dbt-charts/issues/37)
- Partial `style.charts.title` overrides are accepted, and per-family overrides such as `style.charts.bar.title` apply. [Closes dbt-labs/dbt-charts#35](https://github.com/dbt-labs/dbt-charts/issues/35)
- `style.title.font.family` applies to board titles and markdown headings. [Closes dbt-labs/dbt-charts#36](https://github.com/dbt-labs/dbt-charts/issues/36)
- Role tokens such as `category[1]` work in `conditional_formatting` rules. [Closes dbt-labs/dbt-charts#34](https://github.com/dbt-labs/dbt-charts/issues/34)
- `render_dashboard` no longer modifies a `compile_result` passed to it, so rendering the same result twice returns the same status without duplicate warnings.
- Ctrl-C on `dct serve` no longer prints an ASGI traceback, and `dct mcp serve` no longer hangs on shutdown.
- Redshift queries no longer fail with `parameter 'statement_timeout' requires an integer value`. [Closes dbt-labs/dbt-charts#39](https://github.com/dbt-labs/dbt-charts/issues/39)
- Nested items in loose Markdown lists in `text:` blocks are no longer dropped. [Closes dbt-labs/dbt-charts#41](https://github.com/dbt-labs/dbt-charts/issues/41)
- Tables whose percentage column widths sum to 100% no longer fire a spurious `WARN-TABLE-COLUMNS-OVERFLOW`. [Closes dbt-labs/dbt-charts#46](https://github.com/dbt-labs/dbt-charts/issues/46)
- An unknown `dct query` source name raises `ERR-SOURCE-NOT-FOUND` instead of running against an in-memory DuckDB. [Closes dbt-labs/dbt-charts#45](https://github.com/dbt-labs/dbt-charts/issues/45)
- The static column check resolves models ending in `select * from final`, so column typos are caught. [Closes dbt-labs/dbt-charts#40](https://github.com/dbt-labs/dbt-charts/issues/40)
- A diverging gradient's `hinge` is honored on every chart type. Diverging palettes may have an even number of stops, and the legend labels the hinge. [Closes dbt-labs/dbt-charts#48](https://github.com/dbt-labs/dbt-charts/issues/48)
- Board style values such as fonts and colors can no longer inject script into rendered boards.
- `dct serve` no longer reloads endlessly when the query cache lives inside the project.
- `dct render charts/*.yml` skips `meta.yml` with a warning instead of failing.
- An empty board file raises `ERR-EMPTY-YAML-DOCUMENT` instead of `ERR-INTERNAL`.
- BigQuery `invalid_grant` errors note that a new service account key may still be propagating.
- `chart_focus` no longer triggers `WARN-UNREFERENCED-CHART` for every other chart.
- The value-label crowding warning measures the text actually painted, fixing missed and false warnings.
- Category axis labels with a d3 number format or `labels.font.case` no longer clip or overlap.
- `%q`, `%L`, and `%Q` in time formats render correctly. `%c`, `%x`, `%X`, `%Z`, and `%s` fail compile with a clear error.
- Titles and headings use the body text color in every built-in theme. An authored `style.font.color` also colors titles unless `style.title.font.color` is set.
- `dct impact` and `dct validate` report a query whose parenthesized body redeclares a CTE as indeterminate instead of resolving the wrong columns.
- A time format without `%` directives, such as `MMM YYYY`, gets an error suggesting a d3 pattern. Unsupported `%` directives fail at compile instead of `ERR-INTERNAL` at render.
- `dct validate` and the VS Code extension no longer validate `dbt_charts.yml` and `_`-prefixed partials as boards. [Closes dbt-labs/dbt-charts#49](https://github.com/dbt-labs/dbt-charts/issues/49)
- DuckDB `attach`, `extensions`, `settings`, and `secrets` reach the connection. Unsupported keys (`plugins`, `filesystems`, `remote`, `use_credential_provider`) raise. [Closes dbt-labs/dbt-charts#50](https://github.com/dbt-labs/dbt-charts/issues/50)
- A query in a dbt project with no `sources:` and no local DuckDB file under `data/` raises `ERR-DBT-PROJECT-NO-LOCAL-WAREHOUSE` instead of running against an empty database.
- Axis ticks using `percent`, `percent_delta`, `currency_full`, or `number_full` take decimals from the tick step: 10%, not 10.0%.
- `WARN-LIKELY-CURRENCY-OR-PERCENT-MISSING-FORMATTER` no longer asks for a currency format on a column that already has a `%` format.
- `link:` values using `javascript:`, `data:`, or editor schemes fail validation. Unsupported colors such as `currentColor` or `var(--x)` on board titles, the variables strip border, or table links fail the render. Invalid `variables:` names fail at compile.
- Axes with a fixed-decimal `number_format` such as `integer` no longer repeat tick labels on small ranges.
- vivid-10 purple and moss are retuned so color-vision-deficient readers can tell all ten series apart.
- Auto-sized tables reserve their full rendered height. `WARN-TABLE-PAGE-SQUEEZED` fires only for pinned slots and suggests a `style.pagination.page_rows` value.
- A `sort.by` naming a column missing from the query raises `ERR-SORT-FIELD-NOT-FOUND` instead of rendering unsorted.
- Horizontal bars with `axis_x.labels.expr` no longer crowd a top legend.
- A chart's own `style.axis_x.time_unit` takes precedence over chart-type defaults for support-table period labels.
- Axis number formats behave the same at every style tier: predefined names such as `currency` get dbt Charts tick formatting, and literal d3 specs pass through verbatim.
- Nested boards no longer inherit their parent's `style.background`.
- Value labels with `number` or `currency` formats write sub-1 values as digits: 0.67, not "670m".
- A table's Previous button works after a filter shrinks the page count. [Closes dbt-labs/dbt-charts#51](https://github.com/dbt-labs/dbt-charts/issues/51)
- Root-relative `link:` clicks in a board inside an iframe post a `dbt-board-navigate` message to the parent window.
- Titles in a `cols:` row share a baseline when their sizes differ.
- Board text columns align to the card grid of `cols:` rows. `style.text.column.gap` is retired and dropped with a warning; `WARN-ADJACENT-TEXT-ROWS` is removed.
- Boards migrated in memory report `WARN-SCHEMA-MIGRATED` naming the file instead of raw Python warnings, and `dct validate --strict` fails on them.
- Daily line and area charts keep flat, readable date labels when days are missing.
### Performance
- The first board load in a fresh process is faster.
- Long-running hosts can call `dbt_charts.agent_api.warmup.warm_process()` at startup so the first board load does not pay for setup.
- `list_skills` omits skill bodies, cutting a call from about 154 KB to about 20 KB. Use `get_skill` for a body.
- Boards written against an older grammar load faster.
- Tables with many rows or pages size faster.
