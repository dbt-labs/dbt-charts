# dbt Charts

Run `uv tool install dbt-charts && dct skills intro` and follow what it prints.

dbt Charts compiles YAML boards into dashboards. This repo takes no contributions; use it as a
package.

- `dct skills` lists workflows; `dct skills <name>` shows one.
- `dct docs` covers the YAML reference.
- No shell: <https://docs.dbtcharts.com/llms.txt>; full reference in one fetch:
  <https://docs.dbtcharts.com/llms-full.txt>.
